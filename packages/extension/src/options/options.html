Conventional Comments Toolkit

Hôtes autorisés

Seul github.com est pré-déclaré. Les domaines GitHub Enterprise Server, *.ghe.com (résidence de données), Azure DevOps Server et l'hôte de la configuration d'organisation passent par optional_host_permissions, activés à la demande (§A.4, §B.4).

La plateforme choisie détermine quel adaptateur reconnaît ce domaine — un domaine autorisé mais non associé n'active aucune interface (§2). Elle est pré-remplie pour les domaines de produit connus (dev.azure.com, *.visualstudio.com, *.ghe.com), à confirmer ou corriger.

    Préférences locales (§8.1.2)

    Langue, thème, raccourcis, style de badge — jamais le mode ni la liste des labels.

    Télémétrie (§10)

    Désactivée par défaut. Elle n'émet que des compteurs agrégés — label utilisé, code d'erreur, mode, dépôt — jamais le texte d'un commentaire, d'un code ou d'un diff, ni l'adresse de la page. Elle ne s'active que si la politique d'entreprise de votre organisation déclare un point de collecte et que vous cochez cette case. Un dépôt ne peut ni l'activer, ni choisir la destination : cela ne se décide que par la politique du navigateur.
